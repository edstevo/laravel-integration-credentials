# Contributing

## Setup

1. Clone the repository.
2. Install dependencies:

```bash
composer install
```

3. Run tests:

```bash
composer test
```

## Standards

- Format code with `composer format`.
- Run static analysis with `composer analyse`.
- Add or update tests for behavior changes.

## Pull Requests

1. Keep changes focused and small.
2. Include tests for fixes/features.
3. Update README/CHANGELOG when behavior or public API changes.
